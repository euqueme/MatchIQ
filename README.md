# CleverCupid — Match by IQ & Attractiveness (Prototype)

This is a small front-end prototype demonstrating the requested flow:
- Take a photo using the device camera (uploads are disabled; camera only)
- Complete a short IQ quiz
- Complete an attractiveness self-rating; photo is used for a very simple heuristic
- Find matches that are close in IQ and exact match in attractiveness score

Files:
- `index.html` — main UI
- `styles.css` — styling
- `app.js` — prototype logic and sample data

Run:
Open `index.html` in a modern browser (HTTPS or from localhost required for camera access).

Notes:
- The attractiveness scoring here is a demo placeholder only; real face analysis requires careful privacy, consent, and fairness work and shouldn't be implemented lightly.
